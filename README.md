# Daily Programming Practice

A collection of Java programs written while building strong fundamentals in programming, problem solving, and algorithmic thinking.

The repository is organized by topic so that each solution is easy to find, compile, review, and revisit.

## Topics

| Directory | Focus |
| --- | --- |
| [Array](Array/) | Searching, sorting, merging, rotation, duplicates, frequency, and array transformations |
| [Number System](Number%20System/) | Number conversion, Fibonacci numbers, GCD, digit operations, and basic numerical problems |
| [Pattern](Pattern/) | Console-based number, character, and symbol patterns |
| [String](String/) | String reversal, palindrome checks, case conversion, vowels, consonants, and character analysis |

## Technology

- **Primary language:** Java
- **Additional markup:** HTML for small practice demonstrations
- **Style:** Small, focused programs with a `main` method
- **Input/output:** Standard Java console input and output where required

## Running a Program

Make sure the Java Development Kit (JDK) is installed and available on your `PATH`.

From the repository root, compile and run a program using:

```bash
javac String/toUpper.java
java -cp String toUpper
```

The same pattern can be used for programs in the other topic directories. Because the current programs are standalone classes without packages, compile each file from its own directory or provide the directory as the classpath.
